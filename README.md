# 图形推理学习课程：从小白到专家

> Visual Reasoning Course — from Zero to Expert
>
> 一套 **6 阶段 · 24 课** 的图形推理方法论课程：图形是什么、规律从哪来 → 属性/样式/位置/数量规律 → 空间重构 → 组合规律与解题策略 → 出题人视角。带能力里程碑与 8–12 周节奏建议。

- 学习方案：《[图形推理学习方案.md](图形推理学习方案.md)》——痛点诊断、6 阶段学习地图、逐阶段详解、通用工具、规律速查表、节奏建议

## 课程地图（6 阶段 24 课）

- **阶段0 认知奠基**（3 课）——图形是什么、规律从哪来、解题总流程
- **阶段1 属性与样式规律**（3 课）——对称 / 曲直 / 开闭 + 叠加运算
- **阶段2 位置规律**（3 课）——平移 / 旋转 / 翻转（动态规律）
- **阶段3 数量规律**（4 课）——点 / 线 / 面 / 素（核心难点，能系统数全、数对）
- **阶段4 空间重构**（3 课）——折纸盒 / 三视图 / 截面 / 拼接
- **阶段5 组合规律与解题策略**（4 课）——复合规律 + 提速 + 复盘
- **阶段6 专家思维**（4 课）——出题人视角 + 难题 + 原创出题

## 能力里程碑

- 阶段 0 结束 → 说清"图形推理考什么、题长什么样"
- 阶段 1–2 结束 → 单规律题基本不失分
- 阶段 3 结束 → 数量规律能系统数全、数对
- 阶段 4 结束 → 空间题有方法可依，不靠蒙
- 阶段 5 结束 → 组合题有优先级、速度达标
- 阶段 6 结束 → 能讲题、能出题，形成出题人思维

## 阅读顺序

1. 读《方案》"一、方案概览"与"二、痛点诊断"
2. 按阶段 0 → 6 顺序推进，每阶段过对应里程碑
3. 随学随用"五、通用工具"，考前过"六、规律速查表"
